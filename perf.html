Caveats

  • Native was timed by running the translated image.native directly with a raised step limit; the packaged wrapper cannot run these workloads (1M step default limit).
  • Native is about 20-49x slower than C on these compute workloads and about 2.5-10x faster than pure Python.
  • Rust, Go and Python are ports of the registered C programs, not tuned per language. Python is pure loops, no numpy.
  • Shared host with variable load; run 1 includes cold-start outliers in the max column.
  • One host, one architecture. Uru: NOT MEASURED (no port exists).
