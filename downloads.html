General Availability

॥

Sassembly v1.2.1 is generally available: native packages for Linux x86-64, macOS arm64 and macOS x86-64, with a checksum file. Each compiles and runs .t1 programs with no Rust and no emulator. There is no Linux aarch64 package and no Windows build in v1.2.1. The release tree has no Python files. The probe comparison on aarch64-macos (44 of 49 agree in exit code and stdout) was measured on v1.2.0 and not re-run for v1.2.1; see Limits below.

Install: choose a package below, check it against SHA256SUMS-v1.2.1 (steps in Verification), unpack it and run bin/sassembly-build and bin/sassembly-run. A first program, saved as शृङ्खला.t1, prints नमस्ते संसार:

मण्डलम् शृङ्खला ॥
आयातः अष्टक ।

Verification

Do not trust this page. Check it.

A release you cannot check is taken on faith. Check the checksum, then build and run the example from the package.

1,161,026octets — the v1.2.1 Stage 1; Stage 2 equals Stage 1, byte-identical
3native packages in v1.2.1; Linux aarch64 is not shipped
# fetch a package and the checksums, check, unpack, build and run the example
V=v1.2.1; R=v1.2.1-1; T=sassembly-native-$V-TARGET.tar.gz   # TARGET: x86_64-linux, aarch64-macos or x86_64-macos
gh release download $R -R paramtatv/sassembly -p "$T" -p SHA256SUMS-$V
grep " $T\$" SHA256SUMS-$V | sha256sum -c -        # macOS: ... | shasum -a 256 -c -
tar xzf $T && cd sassembly-native-$V-TARGET
bin/sassembly-build -o n.elf example/namaste.t1 && bin/sassembly-run n.elf
# macOS only, if Gatekeeper blocks the files (downloaded via a browser):
xattr -dr com.apple.quarantine .

The release notes record that Stage 2 equals Stage 1, byte-identical. v1.2.1 ships the Stage 1 image as sassembly-v1.2.1-stage1.elf (sha256 269ac263027aea8e173ca04b235eda85efeadbf90d06757c5afc208ddbca24e1, 1,161,026 octets), the same in all three packages. If a package does not match its checksum, we want the bug report.

Building from source

No Rust and no Python needed: tools/t1-build.sh and tools/t1-run.sh use the native Stage 1 and translator, as the packages do. The Rust route (cargo, tools/fixpoint.sh) is not maintained from v1.1.0; the Rust is frozen and archived.

Tools and sources

v1.2 ports 152 files from the monorepo: crates/sadhana-t1, tools, tools/selfcheck, spec/net and docs/adr. The release tree has 0 Python files. The web build and page checks cannot run without the retired wasm toolchain.

Reporting a defect

Include the source, the stage that refused, and the site it named. A refusal always names one; if it did not, that is the defect.
