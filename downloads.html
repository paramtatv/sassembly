Verification

Do not trust this page. Check it.

A release you cannot check is taken on faith. Check the checksum, then build and run the example from the package.

1,146,370octets — the v1.2 Stage 1; Stage 2 equals Stage 1, byte-identical
3native packages in v1.2.0; Linux aarch64 is not shipped
# fetch a package and the checksums, check, unpack, build and run the example
V=v1.2.0; T=sassembly-native-$V-TARGET.tar.gz   # TARGET: x86_64-linux, aarch64-macos or x86_64-macos
gh release download $V -R paramtatv/sassembly -p "$T" -p SHA256SUMS-$V
grep " $T\$" SHA256SUMS-$V | sha256sum -c -        # macOS: ... | shasum -a 256 -c -
tar xzf $T && cd sassembly-native-$V-TARGET
bin/sassembly-build -o n.elf example/namaste.t1 && bin/sassembly-run n.elf
# macOS only, if Gatekeeper blocks the files (downloaded via a browser):
xattr -dr com.apple.quarantine .

The release notes record that Stage 2 equals Stage 1, byte-identical. v1.2.0 ships no standalone Stage 1 image and no provenance file, so there is no octet-for-octet rebuild recipe on this page for v1.2.0. If a package does not match its checksum, we want the bug report.

Building from source

No Rust needed: tools/t1-build.sh and tools/t1-run.sh use the native Stage 1 and translator, as the packages do. The Rust route (cargo, tools/fixpoint.sh) is not maintained from v1.1.0; the Rust is frozen and archived. The native route still needs python3.

Tools and sources

v1.2.0 ports 152 files from the monorepo: crates/sadhana-t1, tools, tools/selfcheck, spec/net and docs/adr. 8 Python files remain in the release tree, and the fixpoint oracle is still Python. The web build and page checks cannot run without the retired wasm toolchain.

Reporting a defect

Include the source, the stage that refused, and the site it named. A refusal always names one; if it did not, that is the defect.
