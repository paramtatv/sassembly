Verification

Do not trust this page. Check it.

A release you cannot reproduce is taken on faith. Check the checksum, then rebuild the image and compare.

951,146octets — the v1.1.0 Stage 1, which compiles its own sources to itself, byte-identical
4native targets, each smoke-tested on its own hardware
# 1 — fetch the image, the checksums and a native package, and check them
curl -LO https://github.com/paramtatv/sassembly/releases/download/v1.1.0/sassembly-v1.1.0-stage1.elf
curl -LO https://github.com/paramtatv/sassembly/releases/download/v1.1.0/SHA256SUMS-v1.1.0
curl -LO https://github.com/paramtatv/sassembly/releases/download/v1.1.0/sassembly-native-v1.1.0-x86_64-linux.tar.gz
sha256sum -c --ignore-missing SHA256SUMS-v1.1.0

# 2 — compile the sources with the native Stage 1; the result must be the image itself
git clone https://github.com/paramtatv/sassembly
cd sassembly && git checkout v1.1.0
tar xzf ../sassembly-native-v1.1.0-x86_64-linux.tar.gz
python3 tools/pack-corpus.py corpus.blob crates/sadhana-t1/src/*.t1
env -u YANTRA_INPUT_ENTRY YANTRA_INPUT=corpus.blob YANTRA_INPUT_NAME=शृङ्खला YANTRA_RAM=2684354560 \
  sassembly-native-v1.1.0-x86_64-linux/lib/stage1.native > sink 2> log
python3 -c "d=open('sink','rb').read(); i=d.index(b'\x7fELF'); open('s2.elf','wb').write(d[i:-1])"
cmp s2.elf ../sassembly-v1.1.0-stage1.elf && echo FIXPOINT HOLDS
# log: halt: Finisher { ... status: Some(1200) }

The native compile took about 26 seconds on a Linux x86-64 host. If cmp reports a difference, the bootstrap is not reproducible on your machine and we want the bug report. A single differing octet is a failure.

What is in the repository

॥ every component, and nothing else
The main parts of the repository, with the Sassembly name of each
ComponentNameDoes
crates/sadhana/साधनम्the toolchain: t1_image and the drivers
crates/yantra/यन्त्रम्the RISC-V emulator and its guard tests
crates/sadhana-t1/src/मूलम्the compiler’s own 21 .t1 sources, which are also the worked example
tools/साधनानिnative tools: t1-build, t1-run, the translator, the self-check suite
spec/नियमाःthe tables the host fills: encodings, grammar, lexicon

Building from source

No Rust needed: tools/t1-build.sh and tools/t1-run.sh use the native Stage 1 and translator, as the packages do. The Rust route (cargo, tools/fixpoint.sh) is not maintained from v1.1.0; the Rust is frozen and archived.

Tests

tools/selfcheck: the native .t1 self-check suite, 80 programs (77 natively, 3 under yantra-run by default) and 23 build refusals, all equal to their expected results on a Linux x86-64 host.

Reporting a defect

Include the source, the stage that refused, and the site it named. A refusal always names one; if it did not, that is the defect.
