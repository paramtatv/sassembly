परीक्षणम्

अस्मिन् पृष्ठे विश्वासं न कुरु। परीक्षस्व।

यत् प्रकाशनं पुनरुत्पादयितुं न शक्नोषि तत् श्रद्धया गृह्यते। योगचिह्नं परीक्ष्य बिम्बं पुनः रचय।

९,५१,१४६अष्टकानि — प्रथमा द्वितीया च अवस्था, अष्टकशः समाने
४स्वयन्त्रीयलक्ष्याणि, प्रत्येकं स्वयन्त्रे परीक्षितम्
# १ — बिम्बं, योगचिह्नानि, स्वयन्त्रीयसङ्ग्रहं च आनय, परीक्ष च
curl -LO https://github.com/paramtatv/sassembly/releases/download/v1.1.0/sassembly-v1.1.0-stage1.elf
curl -LO https://github.com/paramtatv/sassembly/releases/download/v1.1.0/SHA256SUMS-v1.1.0
curl -LO https://github.com/paramtatv/sassembly/releases/download/v1.1.0/sassembly-native-v1.1.0-x86_64-linux.tar.gz
sha256sum -c --ignore-missing SHA256SUMS-v1.1.0

# २ — मूलानि स्वयन्त्रीयया प्रथमावस्थया सङ्कलय; फलं बिम्बम् एव भवेत्
git clone https://github.com/paramtatv/sassembly
cd sassembly && git checkout v1.1.0
tar xzf ../sassembly-native-v1.1.0-x86_64-linux.tar.gz
python3 tools/pack-corpus.py corpus.blob crates/sadhana-t1/src/*.t1
env -u YANTRA_INPUT_ENTRY YANTRA_INPUT=corpus.blob YANTRA_INPUT_NAME=शृङ्खला YANTRA_RAM=2684354560 \
  sassembly-native-v1.1.0-x86_64-linux/lib/stage1.native > sink 2> log
python3 -c "d=open('sink','rb').read(); i=d.index(b'\x7fELF'); open('s2.elf','wb').write(d[i:-1])"
cmp s2.elf ../sassembly-v1.1.0-stage1.elf && echo FIXPOINT HOLDS
# log: halt: Finisher { ... status: Some(1200) }

मूलात् रचना

Rust न अपेक्ष्यते: tools/t1-build.sh tools/t1-run.sh च स्वयन्त्रीयां प्रथमावस्थाम् अनुवादकं च उपयुञ्जाते। v1.1.0 आरभ्य Rust-मार्गः न पाल्यते; Rust स्थगितः सङ्गृहीतश्च।

परीक्षाः

tools/selfcheck: स्वयन्त्रीयः .t1 स्वपरीक्षासमूहः, ८० कार्यक्रमाः (७७ स्वयन्त्रे, ३ yantra-run इत्यस्मिन्), २३ रचनाप्रत्याख्यानानि; सर्वे अपेक्षितफलेन समाः।
